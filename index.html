Connection to BDH & BDH-CQ

BDH (Dragon Hatchling) is Pathway's brain-inspired Post-Transformer architecture. Unlike a standard Transformer, where attention is a dot-product relevance score, BDH reformulates attention as synaptic memory that updates as the model reads each token — structurally closer to how biological neural circuits consolidate information.

BDH-CQ is a later system in the BDH family that learns from demonstrations and reasons without a written chain of thought. It adapts to new tasks by updating recurrent/contextual state at inference time, not by updating weights through gradient descent. Crucially, it requires no evaluation-task demonstrations during training — it generalises from demonstration-conditioned inference alone.

This toy experiment isolates one educational lesson: recurrent memory can process demonstrations, but the demonstrations still need to provide enough information to distinguish the intended rule from competing rules. A real BDH-CQ system faces the same coverage constraint — demonstration-conditioned inference only helps when the demonstrations actually establish the relevant rule conditions.

Our toy learner is not the official BDH or BDH-CQ system. It is a simplified educational artifact that illustrates how demonstration coverage limits extrapolation.

What Did You Learn?

  1. Demonstrations provide evidence about a hidden rule. They are samples, not the rule itself.
  2. Multiple rules can fit the same limited set of demonstrations. Ambiguity is the default, not the exception.
  3. Coverage means meaningful rule conditions, not just more examples. One strategic demonstration can be worth many redundant ones.
  4. Missing coverage causes systematic extrapolation failure — the model's prediction is wrong in a predictable, explainable way because the evidence was never provided.

Limitations

  • The model in this experiment is an educational toy, not a real neural network or language model.
  • The experiment isolates a specific controlled phenomenon — it does not demonstrate universal behavior.
  • More demonstrations do not always improve performance. Informative coverage matters more than quantity.
  • Results from this toy should not be generalized to every model or every task.
  • Real LLMs use far more complex learning mechanisms; this experiment teaches a conceptual lesson about demonstration-based learning.
